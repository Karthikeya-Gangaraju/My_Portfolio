# Karthikeya Gangaraju | Portfolio

A single-page personal portfolio for a Computer Science (Data Science) undergraduate focused on AI and software development. It is one self-contained HTML file with no build step and no dependencies beyond Google Fonts.

## Sections

- **Hero**: introduction, "Explore My GitHub" and "Connect on LinkedIn" buttons, and a profile index of all five external profiles.
- **Projects**: Job Application Tracker and AI Placement Preparation Agent.
- **Problem-solving journey**: LeetCode, CodeChef and HackerRank cards with achievements taken from the resume.
- **Education and skills**
- **Certifications**
- **Contact**: email (with a copy button), then LinkedIn, GitHub and the coding profiles in order of priority.
- **Footer**: all profile links again.

## Features

- Light and dark themes that follow the system setting, with a manual toggle.
- Responsive layout that works down to phone width.
- Keyboard-visible focus states and reduced-motion support.
- Only resume-backed statistics are shown. No ratings, rankings or streaks are invented.

## Run locally

Open `portfolio.html` in any browser. No install or server is needed.

## Deploy with GitHub Pages

1. Create a repository and add `portfolio.html`, renamed to `index.html`.
2. In the repository, open **Settings → Pages**.
3. Choose the main branch and the root folder, then save.
4. The site goes live at the URL GitHub Pages shows.

## Updating content

- **Project repo links**: each project card currently links to the GitHub profile. Replace those two `href` values with the exact repository URLs when you want them to go straight to each repo.
- **Stats and badges**: edit the platform cards in the "Problem-solving journey" section, keeping them in line with your resume.
- **Colours and fonts**: change the tokens in the `:root` blocks at the top of the `<style>` section.
